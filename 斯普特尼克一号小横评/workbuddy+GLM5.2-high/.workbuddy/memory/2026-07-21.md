# 2026-07-21 工作日志

## 斯普特尼克一号 3D 展示网页
- 创建 `index.html`：基于 Three.js 0.160（importmap + ES modules）的纯前端 3D 展示页。
- 3D 模型：球体本体（SphereGeometry 96 段）+ 赤道/经线接缝 TorusGeometry + 16 颗铆钉 + 4 根锥形鞭状天线（2 长 2 短，按斯普特尼克 1 号实际比例），MeshStandardMaterial 金属质感（metalness=1.0, roughness=0.28），RoomEnvironment PMREM 环境贴图反射。
- 交互：OrbitControls 拖动旋转/滚轮缩放/右键平移，空闲 3.5s 后自动旋转，用户交互时暂停。
- UI：纯黑底白字，左上品牌脉动点、左侧主标题、右侧毛玻璃信息面板（含发射日期/在轨天数/直径/质量/绕地圈数/轨道高度 6 项数据）、底部控制提示、2000 颗星空粒子缓慢自转、阴影承接面。
- 本地预览服务器：`http://localhost:8765`（node http 静态服务，后台运行 task_id=xcHAUE）。
- CDN 依赖：unpkg three@0.160.0，需联网加载。
